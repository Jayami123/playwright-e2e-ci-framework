# Agent notes

Rules for AI agents working in this repository (Cursor cloud, Claude Code cloud, or local). Cloud setup:
[docs/cloud-environments.md](docs/cloud-environments.md).

## Rules

- Run `npm run check` before every push.
- Never edit the product forks under `PRODUCTS_ROOT` or anything in `node_modules/qa-portfolio-harness`.
- Start and stop products only through the harness scripts, with the repo `.env` exported first:
  `set -a; . ./.env; set +a; node node_modules/qa-portfolio-harness/scripts/up.mjs <product>` and `down.mjs <product>`. Always finish with `down.mjs`.
- Run Playwright through the npm scripts (`npm run test:medusa -- --grep <id>`), not `npx playwright test --project=...`.
- Never put secrets, seed passwords or API keys in a file, a log or a commit. `.env` is git-ignored; print variable names, never values.
- Do not set `DANGEROUS_BYPASS_RATE_LIMITS` in `.env`.
- Use "the maintainer" or "the owner", never a personal name, in files and commit messages.
- Conventional Commits with lowercase subjects, small logical commits, `git add` by path (never `-A`), no force-push.
- Keep the commit identity from the environment (`GIT_AUTHOR_*` and `GIT_COMMITTER_*`). Do not add `Co-Authored-By`, "Generated with", `Claude-Session` or "Generated by Claude Code" lines.

## Cursor cloud

- `.cursor/environment.json` installs npm packages and Playwright browsers and clones the Medusa fork with
  `scripts/bootstrap.sh medusa`. Docker and the `p1.lvh.me` hosts entry come from its `start` command.
- Other products on demand: `bash scripts/bootstrap.sh cal documenso twenty`.
- Cursor puts its own Node 22 first on `PATH`. Before any harness command run `export PATH="/usr/local/bin:$PATH"`.
- Documenso needs Node 24; `bootstrap.sh documenso` and the harness pick `/opt/node24` themselves.

## Claude Code cloud

- `.claude/hooks/session-start.sh` (cloud only) puts `/usr/local/bin` first, starts Docker, maps `p1.lvh.me`, completes `.env` and
  prints `P1:` hints (stderr) for a missing `/opt/node24`, shellcheck, `CAL_E2E_PASSWORD` or `CAL_DST_PASSWORD`.
- The environment's setup script and network settings are pasted by hand; see the doc above.
