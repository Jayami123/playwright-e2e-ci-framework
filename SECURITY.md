# Security policy

## Supported versions

Only the `main` branch receives security fixes for this repository.

## Reporting a vulnerability

Report issues in **this repo's code, GitHub Actions workflows, or CI artifacts** (for example a secret leaked into a trace, log, or uploaded artifact) through GitHub **private vulnerability reporting**:

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories**.
3. Choose **Report a vulnerability**.

Do **not** open a public GitHub issue for security reports. Do **not** paste passwords, tokens, cookies, or Playwright `storageState` JSON in issues, PRs, or comments.

## Out of scope

Vulnerabilities in **Cal.com**, **Documenso**, **Medusa**, **Twenty**, or other upstream products under test belong to those projects. For Cal.com, see [calcom/cal.com SECURITY.md](https://github.com/calcom/cal.com/blob/main/SECURITY.md).

## Response

This is a solo-maintainer portfolio project. Reports are handled on a best-effort basis; there is no guaranteed response time or SLA.
